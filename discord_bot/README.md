# Об'єднаний Discord-бот

Один бот замість трьох (`Music.py` + `DS.py` + `NewBot.py`), на архітектурі cogs.

Усі команди **гібридні**: працюють і як `!команда`, і як `/команда` (slash).
Slash-команди синхронізуються по гільдіях при старті (миттєва поява).

## Запуск

```bash
# 1. Залежності
pip install -r requirements.txt

# 2. Налаштування (з кореня проєкту)
copy .env.example .env   # та заповни DISCORD_BOT_TOKEN

# 3. Старт
python run_bot.py
```

> Токен зберігається лише в `.env` (gitignored), не в коді. Скинути за потреби:
> Discord Developer Portal → Bot → Reset Token, тоді онови `.env` і перезапусти бота.

## Cogs і команди (префікс `!`)

### 🎵 Музика
`play|p`, `pause`, `resume`, `skip|s`, `stop`, `queue|q`,
`nowplaying|np|now` (з прогрес-баром),
`volume|vol`, `loop song|queue|off`, `shuffle`, `remove|rm <n>`, `clear`,
`join`, `leave|dc`.
- `filter|fx <name>` — аудіоефекти: `off`, `normalize`, `bassboost`,
  `treble`, `nightcore`, `vaporwave`, `8d`, `earrape` (застосовується одразу,
  з перезапуском поточного треку).
- `seek <сек|хв:сек>` — перемотка, напр. `!seek 90` або `!seek 1:30`.
- `lyrics|ly [запит]` — текст пісні (lyrics.ovh). Без аргументу — для поточного
  треку. Формат запиту: `Виконавець - Назва`.
- `nowplaying` показує кнопки керування: ⏯️ пауза/грати, ⏭️ скіп, 🔁 повтор,
  🔀 перемішати, ⏹️ стоп.
- `queue` з кнопками-сторінками: ⏮️ ◀️ ▶️ ⏭️.
- `search|find <запит>` — пошук на YouTube з вибором із топ-5 (випадайка).
- `autoplay|radio on/off` — коли черга порожня, бот сам додає схожі треки
  (YouTube Mix). Налаштування зберігається на сервер.
- **Spotify** — `play <spotify-посилання>` (track/playlist/album). Потрібні
  `SPOTIFY_CLIENT_ID`/`SECRET` у `.env`. ⚠️ З 11.02.2026 Spotify видає ключі Web API лише
  для акаунтів **Premium** (безкоштовно вже не отримати) — код готовий, але без ключа
  Spotify вимкнено. Бот дістає назви і шукає відповідники на YouTube.
  **SoundCloud** — працює без ключів.

### 🎧 DJ-роль / vote-skip
- `dj|setdj @роль` — задати DJ-роль (потрібне право **Manage Server**),
  `djclear|djoff` — зняти. `dj` без аргументу показує поточну.
- **Коли DJ-роль задано:** `skip` для не-DJ працює **голосуванням** — треба більшість
  слухачів у каналі (`ceil(n/2)`; якщо слухач один — скіп миттєвий). DJ-роль та
  адміністратори скіпають одразу. Голоси скидаються при зміні треку.
- `stop`, `clear`, `remove` стають доступні **лише DJ/адмінам**.
- **Без DJ-ролі** (за замовчуванням) — поведінка незмінна: керують усі.

### 📂 Плейлисти (per-user)
`playlist|pl save <назва>` (з поточної черги), `load <назва>`, `list`,
`show <назва>`, `delete <назва>`. Зберігається у `discord_bot/data/playlists.json`.

Автовідключення, коли бот лишається сам у каналі (через 120 с).
Якість: тягнеться аудіопотік з найвищим бітрейтом; фільтри/перемотка через ffmpeg.

> Потрібен **ffmpeg** у PATH (у тебе вже стоїть ffmpeg 8.0 через Chocolatey).

### 🛡️ Модерація (кікер) — тільки адміни
`add_target <id>`, `remove_target <id>`, `list_targets`, `kick_all`.
Список цілей зберігається у `discord_bot/data/targets.json`.
Потрібне право бота **Move Members**.

### 🏷️ Адмін (нікнейми) — потрібне право **Manage Nicknames**
`setnick @user <нік>`, `resetnick @user`, `nickvoice <нік>`,
`resetnickvoice`, `members`.

## Що змінилось vs старі скрипти
- Токен → `.env` (не в коді).
- `!help` тепер працює (стандартний help discord.py).
- Виправлено витік плеєрів і застряглі задачі.
- Зміну **аватарок** прибрано — Discord API не дозволяє боту міняти аватар
  іншого учасника (код у `NewBot.py` ніколи не працював).
- Консольне меню `NewBot.py` замінено на Discord-команди.

Потрібні Privileged Intents у Developer Portal: **Server Members** і **Message Content**.

### ⭐ Обране (per-user)
`fav|like` (додати поточний трек), `favs|favlist`, `favplay [n]` (зіграти все/один),
`unfav <n>`. Також кнопка **⭐** під `nowplaying`. Зберігається у
`discord_bot/data/favorites.json`.

## Деплой 24/7 (Windows, цей ПК)

Файли в `deploy/`:
- `run_24_7.bat` — запускає бота в циклі (автоперезапуск через 10с при збої),
  лог у `deploy/bot.log`.
- `install_startup.ps1` / `uninstall_startup.ps1` — **без адмін-прав**: ярлик у
  «Автозавантаженні», бот стартує при кожному вході в систему.
- `install_task.ps1` / `uninstall_task.ps1` — через Task Scheduler
  (**потрібен PowerShell від адміністратора**); надійніше, з рестартом на рівні ОС.

Швидкий старт (без адміна):
```powershell
powershell -ExecutionPolicy Bypass -File deploy\install_startup.ps1
# запустити вже зараз, не чекаючи перелогіну:
Start-Process deploy\run_24_7.bat -WindowStyle Minimized
```

> ⚠️ ПК має бути увімкнений і користувач — у системі. Для справжнього
> always-on без залежності від твого ПК — краще VPS/Docker.
> Не запускай бот двічі (ярлик + вручну) — буде два інстанси.

## Desktop-панель (tkinter)

`panel/app.py` — графічна панель керування:
- **Запуск/Стоп/Рестарт** бота (супервізує підпроцес + автоперезапуск при падінні);
- **живий лог** (stdout бота), **статус** (онлайн, сервери, аптайм, поточні треки —
  зі `data/status.json`), **редактор `.env`**.

Запуск: `panel\start_panel.bat` (без консолі) або `python panel\app.py`.

Два механізми 24/7 на вибір (не вмикати обидва одночасно):
- **bat** (headless): `deploy\install_startup.ps1` — простий, без вікна.
- **панель** (з UI): `deploy\install_startup_panel.ps1` — на логіні відкриває
  панель (згорнуту), яка сама піднімає й наглядає бота. Цей скрипт прибирає bat-ярлик,
  щоб не було подвійного запуску.

## Веб-дашборд (керування з браузера)

`cogs/dashboard.py` — aiohttp-сервер **у процесі бота**. Вмикається ЛИШЕ якщо задано
`DASHBOARD_PASSWORD` у `.env`. За замовчуванням слухає `127.0.0.1:8765`.

- Вхід за паролем (сесійна кука), сторінка з автооновленням кожні 2.5с + плавний
  локальний тік прогресу. Сучасна темна тема, адаптив під мобільний.
- Зараз грає: обкладинка треку (YouTube thumbnail), **клікабельний прогрес-бар**
  (перемотка кліком), бейджі стану (фільтр / loop / autoplay / гучність).
- Транспорт: пауза/грати, скіп, стоп, **loop** (off/трек/черга), **shuffle**,
  **autoplay**, дропдаун **аудіофільтра**, повзунок гучності.
- **Керування чергою** (повне): грати зараз (▶), вгору/вниз, видалити, перемішати,
  очистити; додавання треку (назва/URL, Enter або кнопка).
- ⚠️ **Безпека:** не виставляй у інтернет напряму. Для віддаленого доступу — тунель
  (напр. Cloudflare Tunnel / ngrok) або реверс-проксі з HTTPS. `DASHBOARD_HOST=0.0.0.0`
  лише якщо розумієш ризики.

Увімкнути: встав `DASHBOARD_PASSWORD=твій_пароль` у `.env`, рестартни бота, відкрий
`http://127.0.0.1:8765`. Якщо порт зайнятий — бот не падає, лише пише warning у лог і
стартує без дашборда.
